### Simon Willison 的浏览器兼容性数据库
*simonw/browser-compat-db*

- **作者**：Simon Willison
- **信源**：Simon Willison
- **时间**：2026-06-24T23:59:03
- **亮点**：
  - 将 MDN 浏览器兼容性数据打包为便携的 SQLite 数据库
  - 利用 AI 辅助编程（Claude Code 和 Codex Desktop）生成转换脚本和自动化工作流
  - 通过 GitHub 仓库的开放 CORS 头实现数据库的在线直接访问与探索

Simon Willison 受 Mozilla 新推出的 MDN MCP 服务启发，将 mdn/browser-compat-data 仓库中的浏览器兼容性数据转换为约 66MB 的 SQLite 数据库，并创建了新的 GitHub 仓库。他利用 Claude Code for web (Opus 4.8) 生成了基于 sqlite-utils 的转换脚本，并借助 Codex Desktop (GPT-5.5) 构建了 GitHub Actions 工作流，该工作流能自动构建数据库并强制推送到一个孤立的 'db' 分支。由于常规 GitHub 仓库中的文件支持开放 CORS 头，生成的数据库文件可通过 GitHub CDN 直接访问，并可使用 Datasette Lite 进行在线探索。

### 提示注入即角色混淆
*Prompt Injection as Role Confusion*

- **作者**：Simon Willison
- **信源**：Simon Willison
- **时间**：2026-06-22T23:59:53
- **亮点**：
  - 揭示了LLM更依赖文本风格而非内容来区分角色的关键漏洞
  - 发现通过简单的“去风格化”改写可大幅降低攻击成功率
  - 提出“角色混淆”是提示注入防御面临的核心挑战

本文介绍了一项关于大语言模型（LLM）提示注入漏洞的研究。研究发现，模型在区分系统指令与用户输入时，更依赖文本的写作风格而非实际内容，这导致了严重的“角色混淆”问题。攻击者可以通过模仿模型内部思考块的写作风格，轻易绕过安全限制。实验表明，对攻击文本进行“去风格化”改写，能将攻击成功率从61%骤降至10%，但这种改写对人类而言几乎无法察觉。研究者指出，除非LLM能实现真正的角色感知，否则提示注入防御将是一场永无止境的“打地鼠”游戏。
