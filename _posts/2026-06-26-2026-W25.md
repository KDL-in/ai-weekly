### 浏览器兼容性数据库
*simonw/browser-compat-db*

- **作者**：Simon Willison
- **信源**：Simon Willison
- **时间**：2026-06-24T23:59:03
- **亮点**：
  - 将 MDN 浏览器兼容性数据转换为便携的 SQLite 数据库
  - 利用 AI 辅助编程（Claude Code 和 Codex Desktop）生成转换脚本和部署工作流
  - 通过 GitHub 孤儿分支和开放 CORS 头实现数据库的便捷分发与在线探索

Simon Willison 受 Mozilla 新 MDN MCP 服务启发，将 mdn/browser-compat-data 仓库中的浏览器兼容性数据转换为 SQLite 数据库。该项目包含一个由 Claude Code for web (Opus 4.8) 生成的脚本，利用 sqlite-utils 完成转换。为使生成的约 66MB 数据库能通过 GitHub CDN 以开放 CORS 头公开访问，他使用 Codex Desktop (GPT-5.5) 构建了一个 GitHub Actions 工作流，自动构建数据库并强制推送到一个独立的“孤儿”分支。用户可直接下载该数据库，或通过 Datasette Lite 在线探索。

### 将 Moebius 0.2B 图像修复模型移植到浏览器运行

- **信源**：Simon Willison

- **亮点**：
  - 利用 Claude Code 全自动完成从 PyTorch 模型到浏览器 WebGPU 运行的完整移植流程
  - 展示了现代浏览器（Chrome/Firefox/Safari）直接运行 0.2B 参数级图像修复模型的能力
