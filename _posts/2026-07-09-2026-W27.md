  - 让 Fable 模型自行判断工作方式比下达具体指令更有效

Simon Willison 分享了从 Claude Code 团队获得的实用技巧：让 Fable（以及 Opus）模型自行判断如何工作，而非下达具体指令。例如在测试方面，与其规定“仅对大型功能进行自动化测试”，不如让模型自行判断何时编写测试。另一个技巧是让 Fable 自行决定将较小的编码任务委派给更低功耗的模型（如 Sonnet 或 Haiku）作为子代理执行，以节省成本。Simon 通过在 Claude Code 中下达指令，成功让系统保存了相关记忆文件，实现了任务自动委派。实践表明，这种方法在保持工作效率的同时，有效减缓了 Fable 额度消耗速度。
