# AI 周报

每周 AI 领域动态精选。

- 在线阅读：https://kdl-in.github.io/ai-weekly/
- RSS 订阅：https://kdl-in.github.io/ai-weekly/feed.xml
- GitHub 用户可直接 Watch 本仓库接收每期更新通知

## 如何发布新一期

1. 在 `_posts/` 新建文件，文件名格式：`YYYY-MM-DD-第NN期.md`（日期不得为未来日期）
2. 文件头包含 front matter：

   ```
   ---
   layout: post
   title: "AI 周报 第 N 期"
   date: YYYY-MM-DD
   ---
   ```

3. commit 并 push 到 `main`，几分钟后自动发布，RSS 同步更新
